# Digvijaysinh Rajput Portfolio

Single-page developer portfolio for Digvijaysinh Rajput, built with Nuxt 3, Vue 3, TypeScript and Tailwind CSS.

## Live Link

[https://digvijay-portfolio-cyan.vercel.app/](https://digvijay-portfolio-cyan.vercel.app/)

## Tech Stack

- Nuxt 3
- Vue 3
- TypeScript
- Tailwind CSS
- Vercel

## Install Dependencies

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

The local development server usually runs at:

```text
http://localhost:3000
```

## Type Check

```bash
npm run typecheck
```

## Build for Production

```bash
npm run build
```
